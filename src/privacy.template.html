01 / ANALYTICS

汇总访问统计

本站使用 Plausible Analytics 了解页面访问量、来源趋势和常见设备类别。统计脚本由 plausible.shipsolo.io 提供；它不设置分析 Cookie，也不进行跨站跟踪。

02 / DATA

可能处理的信息

访问统计可能处理页面路径、来源页面、浏览器和设备类别，以及根据网络请求估算的国家或地区等汇总信息。本站不要求登录，也不设置联系表单。

03 / HOSTING

网站托管

本站通过 GitHub Pages 发布。为交付页面、保障安全和排查故障，托管基础设施可能处理 IP 地址、浏览器标识、请求时间等标准网络日志；相关处理受 GitHub 自身条款约束。
