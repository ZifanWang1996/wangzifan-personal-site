本站是一张公开的个人产品主页。我们只使用维持网站运行所需的托管服务，以及帮助理解页面是否有用的汇总访问统计；不出售访问数据，不用分析结果建立个人画像。

UPDATED / 2026-08-16
01 / Analytics

汇总访问统计

本站使用 Plausible Analytics 了解页面访问量、来源趋势和常见设备类型。统计脚本由 plausible.shipsolo.io 提供。它不设置分析 Cookie，也不进行跨站跟踪。

02 / Data

可能处理的信息

访问统计可能处理页面路径、来源页面、浏览器与设备类别，以及根据网络请求估算的国家或地区等汇总信息。本站不要求登录，不设联系表单，也不会通过该脚本收集你主动输入的内容。

03 / Hosting

网站托管

本站通过 GitHub Pages 发布。为交付页面、保障安全和排查故障，托管基础设施可能处理 IP 地址、浏览器标识、请求时间等标准网络日志；相关处理受 GitHub 自身条款约束。

04 / Choice

你的选择

你可以通过浏览器的内容拦截功能阻止统计脚本，或关闭 JavaScript；这不会影响本站核心内容的阅读。若你通过微信联系，消息将由你所使用的通信平台按其规则处理。
